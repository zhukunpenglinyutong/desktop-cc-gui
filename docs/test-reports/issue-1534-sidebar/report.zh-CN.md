# 侧栏插件导航测试报告

- 日期：2026-11-24。
- 关联需求：[issue #1534](https://github.com/zhukunpenglinyutong/desktop-cc-gui/issues/1534)。
- 基线：上游 `v1.2.6` / `1529def67`，包含设置页深链接展开修复。
- 测试范围：真实 React 组件、宿主自动化与隔离浏览器。覆盖本次侧栏功能及直接受影响的设置页、工作区拖拽、插件权限和核心状态链路。

## 功能和影响范围

两个及以上注册入口收进插件中心下方，默认展开，支持尾随箭头折叠和图标手柄排序。零个或一个入口保持原布局和可见性。插件中心、折叠按钮及图标手柄互相独立。

侧栏顺序按完整入口 id 存在 `ccgui-next.sidebarPluginNavOrder:v1`，折叠态存在 `ccgui-next.sidebarPluginNavExpanded:v1`；设置页与 CLI 偏好保持独立。停用入口保留排序位置，新入口追加。

共享排序组件修复了取消后晚到回调提交、卸载后过期手势及连续拖动定时器串扰，因此同时回归既有工作区跨组移动和设置页导航。插件 SDK、IPC、后端及权限目录保持原契约；没有新增开关、灰度或数据库迁移。

## 执行环境和隔离

macOS / Darwin arm64，Node.js 26.12.0，pnpm 10.29.3，Vitest 3.2.4，本机 Chromium。

组件使用内存存储、示例插件 ID 和 IPC 替身；权限测试使用真实 `createPluginContext` 注册接口及内存后端。浏览器访问本地示例 `/tests/browser/sidebar-plugin-nav.html`，原生 IPC 被替换，localStorage 属于独立测试会话。测试后恢复语言和全局替身，注销临时入口，关闭浏览器及预览服务，不改动用户插件、会话或凭据。

## 交互证据

- 真实图标拖动后刷新：存储及DOM均恢复 `[plugin:sidebar-preview:2, plugin:sidebar-preview:0, plugin:sidebar-preview:1]`。
- 真实拖动生成预览 `[0,1,2]` 后发送匹配指针的取消事件：DOM回滚为 `[2,0,1]`，存储不变，也没有打开页面。
- 三入口减少到一入口：隐藏箭头和手柄，剩余入口恢复旧位置；重新增加到两入口时恢复保存的折叠态。
- 键盘Enter收起、Space展开；中心Enter打开后，箭头收起不会改变中心状态，Tab跳过隐藏入口到新建浏览器。
- 减少动效媒体模拟匹配，计算样式 `transition-property: none`。
- 普通收起逐帧采样得到18个高度值（110px至0），无嵌套按钮；收起区域具有 `inert`。

## 缺陷与复验记录

| ID | 级别 | 复现步骤 | 期望结果 | 实际结果及状态 |
| --- | --- | --- | --- | --- |
| DEF01 | 高 | 预览排序→取消→晚到结束回调 | 回滚且不写入、不误开页面 | 旧实现提交预览；当前回滚且存储不变。已修复，复验通过 |
| DEF02 | 高 | 拖动→重建列表或删除拖动行→旧回调到达 | 废弃旧手势并释放拖拽态 | 旧实现可提交过期顺序；当前采用最新入口集合。已修复，复验通过 |
| DEF03 | 中 | 松开后120ms内开始下一次拖动 | 旧定时器不影响新手势 | 旧实现误取消新手势；当前只提交有效顺序一次。已修复，复验通过 |
| DEF04 | 中（测试阻断） | 运行context-window-memory的broken storage用例 | 写入拒绝后无缓存 | 当前环境原型替身没有拦截存储对象，得到1000000；1项既有失败。保留原断言 |
| DEF05 | 中（测试契约） | 运行text-reference验收的4个history定位场景 | 读取调用与断言契约一致 | 实际调用携带可选undefined参数，断言仅期望路径；4项既有失败。保留原断言 |

DEF04/05已在前次上游原始副本复现，相关实现和失败测试本次均未改动。两组外部插件仓库缺失导致11项既有冒烟跳过。它们单独保留在本次结果中，不通过关闭检查或放宽断言制造通过。
