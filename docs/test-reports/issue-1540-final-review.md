## 修复范围

1. GUI 改名写入原生标题记录和标题副本，扫描识别 CLI 后续改名。
2. 区分未观测和已观测但没有原生标题；新增状态列时使旧扫描缓存失效。
3. 迁移时保护旧 GUI 名称，后续原生改名正常覆盖。
4. 删除对应会话目录，并校验会话身份、路径、只读源、链接和重解析点。
5. 本应用运行中、启动中或正在保存的会话拒绝改名和删除。
6. 分叉写入自身标题，保持编号、正文统计和消息帧身份不变。
7. 可选标题损坏不阻断正文索引，保留上次名称并重试受影响会话。
8. 失败时保护页签、消息和运行状态；明确反馈原生已保存但索引失败的情况。
9. 原生恢复列表继续遵循 CLI 既有规则，可按会话 ID 恢复。

## 终审发现与处理

| 发现 | 根因与处理 | 生产行为影响 |
|---|---|---|
| 首次无原生标题后的改名被旧名称覆盖 | 用独立观测签名区分未观测和已观测空状态 | 修复本问题边界 |
| 新状态列未使扫描缓存失效 | schema 增量迁移同步失效全局扫描缓存 | 修复迁移边界 |
| 普通夹具被链接安全检查拒绝 | 测试临时目录改为物理路径；专门链接拒绝用例保留 | 仅测试夹具 |
| 非 UTF-8 文件名不能建立 | 直接验证入口在文件探测前拒绝，检查明确错误类别 | 仅测试夹具，拒绝断言更严格 |
| CLI 分发断言受本机安装影响 | 为独立安装分支使用私有二进制夹具，包目录断言及期望值保留 | 仅测试夹具 |
| 存储故障模拟未生效 | 拦截实际存储对象，并增加模拟必须被调用的断言 | 仅测试夹具 |
| 历史文件定位的可选参数断言不兼容 | 保留一次调用、准确路径、没有编码覆盖的断言，兼容省略和显式空值 | 仅测试夹具 |
| PID 文件存在但内容尚未就绪 | 在原超时内等待有效正数 PID，保留中断、退出及注册表清理断言 | 仅测试夹具 |

未削弱生产路径校验、权限检查或进程退出要求；未增加忽略或跳过用例。
