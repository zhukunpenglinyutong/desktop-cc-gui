# 多会话并行 CPU 排查与修复

## 结论与边界

截图中 Graphics and Media 为 30.5%，是优先调查图形绘制的线索，不能单独证明根因。本次确定并修复了两类随并发增加的额外工作：运行状态点每帧重绘阴影，以及后台会话更新触发当前会话的重复历史查询。

未重启或替换正在运行的安装版，未调用模型发送测试消息。以下数字来自合成负载，不能直接换算为截图所示进程或整机 CPU 的降幅，也不能证明所有偶发峰值已经消失。

## 修复

- `src/styles/globals.css`：侧栏、页签、收起的 worktree 共用的状态点保留 0.92s 呼吸，阴影只绘制静态外观，关键帧仅改变缩放和透明度。重试、未读完成与减少动态效果的静态状态保持原语义。
- `src/features/chat/components/use-tab-model-display.ts`、`QuestionDock.tsx`、`PlanReviewDock.tsx`：不重复扫描未变化的消息数组；复用 `memoize-message-history.ts` 的每个 hook 单条缓存，没有按会话无限累积的 Map。审批恢复标识参与失效，streaming 在缓存外实时判断。窄订阅仍返回字符串、原消息引用或布尔值，避免把消息变化扩大成输入框重渲染。
- 消息接收、流式批处理、内容、排序与存储逻辑不变。核查过问题状态、审批和模型事件的写入路径，均替换消息数组；插件 effort 设置更新独立字段，继续立即生效。
- 增加 `session-history-selectors.test.tsx`、`tests/browser/concurrent-status.html` / `.tsx`，同步浏览器 README 与 UI 规范。
- 扩大验证时发现 `session-model-memory.test.ts`、`store.test.ts` 的原有 IPC mock 缺少生产代码已调用的 `listPlanReviews`；各补一行空计划列表 mock，保留所有断言。

## 测量

### 历史查询

真实 React + Zustand 回归：可见会话保持 2,000 条合成历史，后台会话更新 100 次，可见历史数组引用不变。旧代码额外读取 model 200,000 次、effort 200,000 次、question 相关 role 200,000 次、planReview 400,000 次，合计 **1,000,000 次**；修复后为 **0 次**。前后组件均无额外重渲染，改善的是 React 渲染前的 selector 查询工作。

新测试先在旧代码上出现两个性能断言失败，行为断言通过；修复后全部通过。覆盖无关状态与 usage 更新、追加与替换历史、会话切换、分屏作用域、空会话、active model/effort 更新及回落、审批 resume、streaming 停止与恢复。

### 状态动画

Chromium 无头浏览器，1280×720、DPR 2，使用生产状态点 CSS；每会话一个侧栏点与一个页签点，每组预热 1 秒、采样 3 秒，前后交替各 3 轮。中位数如下。Paint 是 trace 事件数，同一帧可能有多个事件，不是屏幕帧数。

| 并发会话 | Paint 事件：旧 → 新 | 主线程 TaskDuration：旧 → 新 |
|---|---:|---:|
| 1 | 1,083 → 0 | 169.65ms → 2.70ms |
| 6 | 4,680 → 0 | 192.10ms → 3.45ms |
| 12 | 9,025 → 0 | 288.90ms → 2.89ms |

以上隔离实验只包含状态点与静态文字，不包含 IPC、Markdown、模型进程或完整应用。另用真实 `AiChatSidebar` 与 `SessionTab` 夹具重复 trace：修复后 9 个窗口中 8 个为 0 次 Paint、1 个为 1 次（0.02ms）；正常运行时仍有 12 个呼吸动画，属性仅为 transform / opacity。真实组件旧版采样有明显环境波动，因此不从该组推算百分比收益。

优化方向也与浏览器建议相符：[web.dev 的动画性能指南](https://web.dev/articles/animations-guide) 建议优先将动画限制在 transform / opacity，并通过 Paint trace 核验。

## 验证

- Chromium 和 Playwright WebKit 各验证 36 种组合：1 / 6 / 12 会话 × 运行 / 重试 / 完成 × 正常 / 减少动态效果 × 亮 / 暗主题，全部通过、无页面异常。
- 两种引擎各连续采样 10 帧，缩放值变化、阴影值恒定；亮暗截图保持布局与状态点可见性。WebKit 测试引擎不等于安装版 Tauri 所用的系统 WebKit。
- 前端类型检查与构建通过。构建保留已有 `::highlight`、静态/动态重复导入与大 chunk 警告；项目没有独立 lint 脚本，未增加依赖。
- Node 流式、Unicode、Markdown 与缓存回归 40 / 40 通过。
- 聊天测试首次扩大运行 527 / 533 通过，6 项均因上述原有 IPC mock 缺失失败；修复 mock 后两个文件 46 / 46 通过，最终整组 **59 文件、533 / 533 用例通过**。
- 独立代码审查未发现阻塞问题，变更差异检查通过。本次不涉及 Rust 生产代码，未将其他任务的后端修改作为本次验证对象。
